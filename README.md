# 🚗 AutoHub Oracle System

## 📋 Giới Thiệu

AutoHub Oracle System là một ứng dụng web quản lý bán xe ô tô được phát triển bằng ASP.NET MVC và Oracle Database. Hệ thống cung cấp các tính năng quản lý xe, khách hàng, đơn hàng cùng với các cơ chế bảo mật nâng cao như mã hóa dữ liệu và kiểm toán (audit logging).

## ✨ Tính Năng Chính

- 🔐 **Quản lý tài khoản và phân quyền**: Role-based authentication
- 🚙 **Quản lý xe**: Thêm, sửa, xóa thông tin xe
- 👥 **Quản lý khách hàng**: Lưu trữ và quản lý dữ liệu khách hàng
- 📦 **Quản lý đơn hàng**: Tạo và theo dõi đơn hàng
- 💬 **Feedback**: Hệ thống đánh giá từ người dùng
- 🔒 **Bảo mật nâng cao**: 
  - Mã hóa dữ liệu nhạy cảm
  - Oracle Label Security
  - Virtual Private Database (VPD)
- 📊 **Audit Logging**: Ghi nhận toàn bộ hoạt động hệ thống
- 👨‍💼 **Admin Dashboard**: Giao diện quản trị

## 🛠️ Công Nghệ Sử Dụng

### Backend
- ASP.NET MVC 5.2.9  
- .NET Framework 4.8  
- Entity Framework 6.5.1  
- Oracle Database (Oracle.ManagedDataAccess 23.26.0)

### Frontend
- Bootstrap 5.2.3  
- jQuery 3.7.0  
- jQuery Validation  
- Modernizr
